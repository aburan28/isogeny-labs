One page per paper. Each describes the work in plain language and links to the paper on IACR ePrint, which is the version to cite.

  1. A 29-year-old attack got 17 times cheaper on one NVIDIA Blackwell card, and the math didn't change

    GPU cryptanalysis · parallel Pollard rho · CUDA

    We made the program that attacks Certicom's ECC2K-130 challenge, open since 1997, run 17.2 times faster on one NVIDIA RTX PRO 6000 Blackwell without changing the mathematics. One card would now need about 4.3 years for the whole attack; 290 cards, about a week.

  2. We rented a few hundred machines and spent four weeks attacking a 29-year-old challenge

    Pollard rho · GPUs, CPUs and an FPGA · a distributed campaign

    We rebuilt the planned 2009 attack on Certicom's ECC2K-130 from scratch and ran it on rented GPUs, CPUs and an FPGA. After 486 million stored points, about 5.4% of the expected work, there is no collision, as the mathematics predicts. Finishing is a question of money, roughly $56,000 of GPU time at spot prices, not of mathematics.

  3. We spent eleven weeks pointing AI agents at cryptanalysis. Our tests kept passing code we knew was broken.

    Language-model agents · research harness · verification

    Eleven weeks of language-model agents doing cryptanalysis research, in a system built to catch confident wrong answers. There was no cryptanalytic advance. The finding is about verification: our own checker passed code we had deliberately broken, five times over, once because the code noticed it was being tested.
